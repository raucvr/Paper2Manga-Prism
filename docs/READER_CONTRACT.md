# 让读者先明白，再认识术语

新生成的 v3 漫画使用 `brief.reader_contract = "novice_v1"`。旧作品不自动改稿，重新排版也不把旧作品标为新标准。

读者应当能沿着这条线读下去：

1. 我们想完成什么任务？
2. 现在卡在哪里？理解这件事需要哪些背景？
3. 论文改了哪一步？同一个例子经过这一步后有什么不同？
4. 为什么这样改有帮助？
5. 数据支持到了哪里，还有哪些限制？

开头列两三个普通人能理解的问题。术语在需要它时出现，紧跟已经讲过的直觉。每格只引入一个新概念；一条复杂主张可以分几格讲，但数字、比较条件和限定语仍须完整保留。结尾回答开头的问题。

OnQ 样稿见 [前后对照](readability-preview/index.html)。重点是解释“学生实际写出的内容”和“固定答案中的内容”为什么可能不同，以及老师为什么需要针对前者给出下一步的指导。不能把尚未选出的候选词当成已经写出的前文，也不能把走另一条路线直接说成答错。

## 两种检查各回答一个问题

原有事实检查、数值检查和摘要测验继续检查论文信息是否保留。新的阅读复述检查只看到最终读者可见的文字、图中文字及关系，不提供原论文、隐藏词汇表或标准答案。它要解释任务、问题、方法、原因和限制，并引用面板原话。答不出、引用不存在、接口失败均不能记为“检查无问题”。

该检查是 AI 提供的修改线索，不是人类读者已理解的证明。它目前只诊断并提示，不保证自动修好每一处问题。中文等译本在翻译和校对后单独检查；任何可见内容改变都会使旧记录失效。页面提示未解决的问题或检查不可用，不展示“理解通过”的分数。

## 内容验收

请读者合上样稿，用自己的话说：想解决什么问题、论文改了哪一步、为什么这一步可能有帮助。复述困难的位置就是需要重写的位置。模型分数、测试通过数和配图精美程度都不能替代这一步。
