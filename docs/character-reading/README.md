# OnQ：带角色的完整阅读试作

这一版将前一轮 37 格中文教学稿实际绘制为 **38 格漫画**，包括 16 格场景和 22 格图解。沿用 Papi、Kumo、Nezu 三张角色设定图，结合角色站位、脸部、动作、教学道具、对白和图板重新审查构图。

所有工作都在 `Prism_manga-reader-readable` 的 `codex/prism-readable-content` 分支；未写入原始工作目录。

## 阅读与交流包

本机完整素材在 `output/character-reading-20261106/`。`public/index.html` 可以直接离线打开；同目录图片必须一起保留。预览支持章节跳转、整格放大、图解单独放大、可展开的逐格文字和键盘关闭。

交流包包含带字漫画、无字角色原画、角色参考、实际绘图提示、最终分镜、定位与排版数据、浏览器与内容检查记录。它不包含 API 配置、密钥或其他运行目录。

## 这次实际改变了什么

- 根据文字量预留 36%–54% 的文字区，而不是对每格使用同一模板。角色按发言顺序站位；图解格保留独立白板，避免角色遮住图表。
- 重写隐藏画面要求，去掉多余老师/学生等新角色，以及会暗示未经论文证明的无限循环、速度或样本数量的画法。第 26 格曾多画一枚样片，已重画为三个托盘、每盘两枚。
- 原第 32 格同时讲“截断率”和“回答变短”，实际合成后图表只剩 304px 高。拆为相邻两格后，图表恢复 400px 高，主格对白由 36px 增至 48px。新增格的内部 ID 是 38，阅读顺序为 `32 → 38 → 33`，不要按 ID 数值重新排序。
- 同一角色连续发言合并为一个气泡；所有原有旁白、对白和图解内容均保留，检查只忽略合并引入的空白。
- 修复排版器错过顶部空白的问题：原策略无法放下时，才增加较宽气泡和从上到下的候选，保持字号下限。
- 第 11/12/17 格的旁白属于先修定义。为保护道具，它们使用上方独立旁白条，画布增加 174px，原画和字号不变。其他同时包含对白或图表的复杂 fallback 保持原行为。
- 气泡尾巴同样避开教学道具；修复了第 24 格尾巴碰到夹具边缘的问题。

## 模型与人工编辑边界

前一轮正文由 Claude Opus 5.5 重写、GPT-6 Astra 对照论文审阅，主代理核对编辑。本轮 GPT-6 Astra 参与构图、道具保护和排版回归，主代理完成绘图编排、合成和阅读预览。

本轮角色画面使用 **OpenAI 内置 image_gen 工具**，工具未暴露底层确切模型 ID；不要将它写成项目原生 Seedream 流水线的生成结果。角色/白板定位实际使用项目配置的 `seed-2-0-pro-260328`，对白和图表由项目代码绘制。定位曾有超时，成功结果按格缓存后补齐，最终 38 格全部完成。

这是经过编辑与实际合成的阅读试作。前一轮自动文本流水线仍未完成，不能把此交付说成全自动端到端验收成功；也尚未进行人类理解测试。

## 离线重建

在此分支的项目环境中运行；`--run` 指向完整素材目录：

```sh
.venv/bin/python docs/character-reading/render_panels.py --run output/character-reading-20261106
.venv/bin/python docs/character-reading/build_preview.py --run output/character-reading-20261106
```

两个命令都不调用模型。重排前校验原画哈希与道具审查，拒绝将旧定位用于被替换的画面。新原画必须重新定位和审查后再生成清单。`build_preview.py` 遇到未完成的带字图会报错，不输出假装完整的画册。

后续阅读反馈请记录具体格序号，以及卡在“词义”“因果关系”“图和对白对应”还是“字太小”；先改真实阅读障碍，再考虑更丰富的场景变化。
