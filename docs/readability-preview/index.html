新版开头（编辑示范稿）

每格只讲一个新想法。图上标明哪些是示意，哪些原样取自论文图 2。展开“出处”可以看到对应的论文行号。

1

一道要写很久的题

  • 讲解模型解一道复杂数学题，可能要写很长的步骤。
  • 讲解它每次接着已写内容，生成下一个文字片段。
出处
  • paper.txt L36–L39 论文分析 MATH-500 数学题，其中一些题会让原模型写出很长的回答。
  • L193–L196 学生自己采样回答，每一步都以“题目＋已写部分”为条件。
  • L40–L42 回答越长，学生越依赖自己已经写出的内容。

边界：“文字片段”指 token，可能是词的一部分或标点，不等于一整步推理。这里不给题目内容或长度数字。

读之前，先带着三个问题

  1. 为什么要把模型压小？压小会改变什么？
  2. 旧的补救训练，哪里没对上？
  3. OnQ 换了什么做法？作者为什么认为它有帮助？
2

为什么想把它变小

  • 提问为什么要把模型变小？
  • 讲解大模型很占内存。压小后，部署更方便。
出处
  • paper.txt L27–L28 低位量化降低大模型的内存占用，让部署更实际。

边界：不说压小后就一定能装进某台具体设备。论文开头没有给出这种量化结论。

3

用更粗的刻度存数字

  • 讲解用较少几档，来保存模型里的数字。
  • 讲解这叫量化。存着更省空间，但有些数会变。
出处
  • paper.txt L133–L140 公式 1：权重除以尺度、四舍五入、加零点，再截到 [0, 2^N−1]；前向计算使用还原后的权重。
  • L138–L139 同一组权重共用尺度和零点。

边界：图中的档位数量只是示意，不代表论文设置。位数和档位的关系放在术语表。

4

老师和学生，是两个模型

  • 讲解压小可能伤到推理，所以还要继续训练。
  • 讲解让压小后的学生，向原来的老师模型学习。
出处
  • paper.txt L28–L30 前人工作报告，低精度推理模型准确率明显下降、生成效率变低（论文的引述）。
  • L30–L33 QAT 用量化后的前向计算调整参数，通常由原始全精度模型监督。
  • L74–L75 老师是冻结的全精度模型。L243–L244 每个学生由它对应的原始 BF16 模型监督。

边界：“看齐”指向老师的下一个词概率分布靠拢，不表示老师掌握事实真相。

5

旧做法：沿着备好的答案练

  • 讲解旧做法：沿着事先备好的答案训练。
  • 讲解每一步，都学老师更倾向接哪些文字。
出处
  • paper.txt L8 现有方法通常在固定回答序列上用原始全精度模型监督量化学生。
  • L33–L35 这些蒸馏方法在固定回答序列上训练，效果取决于训练前缀能否覆盖学生推理时遇到的前缀。
  • L40 固定回答蒸馏只监督参考前缀。L95–L96 几种基线都在固定训练序列上计算老师监督。
  • L102–L103 图 2 固定路线：“… not the case . So …”（PDF 抽取中的多余空格已合并）。

边界：不说固定答案是老师写的（基线用的问答对来自数据集，见 L489–L490），也不说它对或错。

6

补救后，仍可能写不完

  • 提问这样补救，问题就解决了吗？
  • 讲解论文测试的长题中，它常写到长度上限仍没结束。
出处
  • paper.txt L9–L11 QAT 之后的低位模型在长推理任务上仍然吃力，常常在原模型够用的 token 预算内停不下来。
  • L36–L40 Qwen3-1.7B 2 比特、MATH-500：对原模型会写得很长的题，QAT 基线常常写到 token 上限（图 1b）。

边界：示意图不是图 1 的数据，这里不给百分比。“它”指用旧做法补救过的低位学生。

7

自己写时，可能换一条路

  • 讲解学生自己写时，可能接上 Wait（等一下）。
  • 讲解接下来的内容变了，旧训练未必覆盖。
出处
  • paper.txt L102–L107 图 2：固定路线 “… not the case . So …”；量化模型的续写 “… not the case . Wait , the problem says …”。
  • L40–L41 量化改变了学生的生成方式，固定回答蒸馏只监督参考前缀。
  • L11–L13 固定回答监督使训练前缀和学生生成时的前缀不一致。

边界：论文没有说 Wait 是错误，也没有说这次分岔导致了截断或答错。

8

长回答，更容易偏离

  • 讲解每次续写，都接着自己已经写出的内容。
  • 讲解作者观察到：回答越长，这种偏离越明显。
出处
  • paper.txt L40–L42 回答越长，学生越依赖自己的输出，上下文离参考前缀越远。
  • L12–L13 这种轨迹偏离随回答变长而增大。

边界：曲线形状只是示意，论文没有给出这种距离曲线。

9

OnQ：先让学生自己写

  • 讲解OnQ 让学生先自己写，再让老师看这份回答。
  • 讲解老师逐步给出下一段文字的偏好；学生学习后，再写一轮。
出处
  • paper.txt L17–L18 从块级校准出发，量化学生生成回答，并在自己的前缀上接受全精度老师监督。
  • L125–L129 学生采样回答，老师在同样的前缀上给出下一个 token 的分布。
  • L193–L197 老师在每个学生生成的前缀上给出分布，包括含有学生早先错误的前缀。
  • L226–L230 更新后的学生生成新的回答，让监督对准学生当前会走到的前缀。
  • L106–L108 图 2 左侧 “on-policy (ours)”：在量化前缀上给出全精度目标。

边界：老师给的是它自己的下一个 token 分布（蒸馏），不是事实纠错。没有展示或编造老师的具体概率。

10

为什么这样教

  • 讲解练习材料，来自学生这一轮自己写出的内容。
  • 讲解这样更贴近它会遇到的情况；是否有效，还要看实验。
出处
  • paper.txt L42–L43 轨迹偏离促使作者让老师在学生自己的轨迹上监督。
  • L128–L129 这种同策略监督用来应对轨迹偏离（原文：addresses trajectory divergence）。
  • L113–L116 相关领域认为，在学习者自己的输出上训练可以缓解暴露偏差。

边界：只转述作者的动机和设计意图，不承诺完全恢复，这里也不引用实验结果。

回到开头的三个问题

1. 为什么要把模型压小？压小会改变什么？
压小是为了少占内存。量化用更少档位存数字，节省空间，也可能改变模型的计算。
2. 旧的补救训练，哪里没对上？
旧方法沿着固定答案训练；学生自己写的内容可能不同，长回答中的偏离更明显。
3. OnQ 换了什么做法？作者为什么认为它有帮助？
让学生先写，老师针对它已写出的内容指导下一步。训练更贴近学生本轮的行为；效果和边界仍要看实验。
术语表（可选，读完再看）
参数 / 权重parameters / weights
模型内部决定输出的大量数字，量化处理的就是这些权重。L133–L140
量化quantization
把每个权重四舍五入成一个 N 比特整数编码，取值范围 0 到 2^N−1，计算时再按尺度和零点还原。L133–L138
2 比特 / 3 比特W2 / W3
论文研究的两种权重位宽。位数越少，可用的档位越少。L239–L240
全精度模型full-precision model
没有量化的原模型。本文用它当老师，训练中保持冻结。L74–L75
量化感知训练（QAT）quantization-aware training
量化之后，用量化后的前向计算继续训练参数，通常由全精度模型来监督。L8, L30–L33
蒸馏distillation
让学生的下一个 token 概率分布向老师的分布靠拢。它学的是老师的倾向，不是由外部判定的对错。L32–L33, L195
token / 词元token
模型一次写出的最小单位，可能是一个词、词的一部分或一个标点。正文口语化地称为“文字片段”。
token 预算 / 长度上限token budget
允许一个回答写到的最大长度。写到上限还没结束，回答就会被截断。L9–L11, L38–L39
前缀prefix
到某一步为止已经写出的内容（包括题目）。下一个 token 是以它为条件预测的。L195–L196
固定回答监督fixed-response supervision
只在事先备好的固定回答序列上计算老师监督。L8, L33, L40
轨迹偏离trajectory divergence
训练时的前缀和学生自己生成时遇到的前缀不一致，而且回答越长偏得越远。L11–L13, L40–L42
同策略蒸馏（OPD）on-policy distillation
老师监督的是学生自己生成的前缀，学生当前的行为本身成为训练分布的一部分。L16–L18, L115–L116, L125–L129
块级校准block-wise calibration
OnQ 的起点：逐个 Transformer 块，让量化块的输出接近全精度块的输出。L141–L143, L185–L191
Dynamic KL（本预览未展开）candidate-wise Dynamic KL
OnQ 的第二部分。它处理另一个问题：学生在同一个前缀上，对一些候选词估低、对另一些估高。本预览没有讲这一部分。L14–L20, L198–L215
